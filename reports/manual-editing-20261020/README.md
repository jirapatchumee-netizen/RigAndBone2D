# จัดชิ้นภาพและแก้กระดูกด้วยตนเอง

เปิด RigAndBone2D รุ่นที่ build แล้วจาก `dist/RigAndBone2D.app` และเปิดโปรเจกต์ Chibi เดิมได้ทันที

1. เลือกชิ้นจากรายการด้านซ้าย
2. เปิด **Move image** แล้วลากภายในกรอบภาพสีเหลือง ข้อต่อและกระดูกลูกไม่ขยับ
3. ใช้ **Image X / Image Y** เพื่อปรับตำแหน่งละเอียด ตัวเลขเป็นหน่วยภาพบนแกนของกระดูก จึงหมุนตามกระดูกในแอนิเมชันทุกเฟรม
4. ปรับ **Layer** ให้ชิ้นที่ต้องการอยู่ด้านหน้า ค่าสูงวาดทับค่าต่ำ
5. ใช้ **Reset image position** เพื่อคืนตำแหน่งภาพเดิม แล้วกด **Save…** เพื่อเก็บงาน

ปิด Move image เพื่อกลับไปลากหมุนกระดูก ใช้ Shift-drag เพื่อย้ายข้อต่อพร้อมลูก การลากภาพเลือกชิ้นเดิมก่อนถ้าอยู่ในกรอบนั้น หากอยู่นอกกรอบจะเลือกภาพชั้นบนสุดที่ครอบตำแหน่งเมาส์ พื้นที่โปร่งใสภายในกรอบถือว่าคลิกโดนภาพได้

**Add child bone** และปุ่ม **Add bone** ด้านบนเพิ่มกระดูกลูกของกระดูกที่เลือก คีย์เฟรมเดิมเพิ่มมุมเริ่มต้นให้กระดูกใหม่ **Delete bone…** แสดงชื่อและจำนวนลูกก่อนยืนยันลบทั้งกิ่ง ข้อมูลของกระดูกที่เหลือและมุมในคีย์เฟรมถูกจัดดัชนีใหม่ การลบยังไม่มี undo และไม่อนุญาตให้ลบจนไม่เหลือกระดูก

ภาพเลื่อนได้แยกจากกระดูกโดยไม่ต้องเปลี่ยน pivot สำหรับงานซ้อนข้อ แต่เส้นดำและเงาปิดปลายชิ้นในต้นฉบับยังอาจต้องเก็บงานภาพเพื่อให้ต่อเนื่องเหมือนตัวอย่างฝั่งซ้าย

## หลักฐาน

- `editor-before.jpg` และ `editor-dragged.jpg` เป็นภาพหน้าจอก่อนและหลังลาก torso
- `Manual-moved.rig2d` เป็นไฟล์บันทึกผ่าน GUI จริง ลาก 36 × 18 screen pixels ที่ zoom 1.8 ได้ image offset 20 × 10
- `gui-proof.json` และ `gui-readback.json` ยืนยันว่ามีเฉพาะ offset ของ torso เปลี่ยน โครงกระดูกลูกและคีย์เฟรมเหมือนเดิม
- GUI เพิ่มกระดูกได้จาก 17 เป็น 18 กระดูก จากนั้นตรวจหน้าต่างลบโดยไม่ได้ยืนยันลบ การลบจริงตรวจผ่าน API integration tests
- `delete-confirmation.jpg` แสดงหน้าต่างยืนยันลบ

Build ผ่าน พร้อม agent_smoke, agent_workflow 15 tests, render_orientation, demo_reproducibility, asset_replacement 5 tests, image_offsets 4 tests, bone_editing 5 tests, godot_bridge และ spritekit_bridge

การตรวจทานแยกพบกรณี batch ส่งคีย์เฟรมผิดจำนวนแล้วลบกระดูกทำให้ API หยุดทำงาน ทำซ้ำได้ก่อนแก้ จากนั้นเพิ่มการตรวจจำนวนมุมที่คำสั่ง keyframe และ regression test ตอนนี้คืน validation_failed โดยไม่แก้ไฟล์และรับคำสั่งถัดไปได้

API ใช้ `set_bone.values.imageOffsetX` และ `imageOffsetY` ส่วน `delete_bone` ต้องระบุ `include_descendants:true` เมื่อลบกระดูกที่มีลูก ทั้งสองรองรับ batch และ revision เดิม ดูรายละเอียดใน `docs/AGENT_API.md`
