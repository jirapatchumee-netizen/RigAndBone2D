# รายชื่อเดียวและ Undo

แอปรุ่นล่าสุดมีรายการ PARTS ฝั่งซ้ายเพียงรายการเดียว ลากชื่อขึ้นเพื่ออยู่หน้า ลากลงเพื่ออยู่หลัง ไม่ต้องเลือกโหมดและไม่มีช่อง Layer ตัวเลข

ใช้ ⌘Z ย้อนกลับ และ ⌘⇧Z ทำซ้ำ รองรับการเรียงภาพ ลากภาพหรือกระดูก แก้คุณสมบัติ เพิ่มหรือลบกระดูก เปลี่ยน PNG และคีย์เฟรม ประวัติเก็บ 100 รายการใน session เดียว หนึ่งครั้งที่ลากนับเป็นหนึ่งรายการ Save เก็บประวัติไว้ แต่ Open/New เริ่มประวัติใหม่ ระหว่างแก้ข้อความ ⌘Z ย้อนข้อความ เมื่อยืนยันค่าแล้วคลิกกลับรายการหรือ canvas เพื่อย้อนการแก้โปรเจกต์

## ผลตรวจจริง

`chibi-check/gui-proof.json` ยืนยันการลาก upper-arm-back ไปไว้เหนือ torso ผ่านรายการเดียว การกด ⌘Z คืน JSON โปรเจกต์ตรงต้นฉบับ และ ⌘⇧Z คืนผลการลากเดิม การบันทึกระหว่างขั้นตอนยัง Undo ต่อได้ และข้อมูลเปลี่ยนเฉพาะ layer

ภาพหน้าจอและไฟล์ที่บันทึกผ่าน GUI อยู่ใน `chibi-check` ใช้ `tests/undo_gui.mjs` ผ่าน Node REPL กับแอปและสำเนา Chibi ที่แยกไว้เพื่อทำซ้ำ ตัวตรวจใช้ viewport 1280 × 848 ตามภาพหน้าจอของแอปรุ่นนี้

`tests/undo_history.py` compile Editor ตัวจริงกับ AppKit harness เพื่อทดสอบการเพิ่มกระดูก การย้อนกลับและทำซ้ำ การรวมการลากเป็นหนึ่ง action no-op การล้าง redo เมื่อแก้ใหม่ การไม่ย้อน file revision และขีดจำกัด 100 actions

การตรวจทานแยกไม่พบข้อผิดพลาดใน snapshot/revision มีข้อจำกัดตามการทำงานปกติของช่องข้อความว่า ⌘Z ขณะพิมพ์ย้อนข้อความก่อน

รอบทดสอบก่อนหน้า `ui-run-1` ถึง `ui-run-3` เป็นหลักฐานระหว่างพัฒนา ไม่ใช่ผลผ่านฉบับสุดท้าย รอบแรกพบปัญหา native undo action naming นอกกลุ่มและแก้แล้ว รอบต่อมามีการเปลี่ยนข้อกำหนดให้ตัดโหมดออก ผลผ่านฉบับสุดท้ายใช้ `chibi-check/gui-proof.json`

ตัวละครต้นฉบับไม่ถูกเขียนทับ สำเนาที่ใช้ดูหน้าจอคือ `chibi-check/Chibi-preview.rig2d`
